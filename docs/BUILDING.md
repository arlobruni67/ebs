# Building EBS from source

EBS is a Cargo workspace (`crates/engine`, `crates/app`, `crates/bench`) for Windows x64.

## You need

* Rust with the `x86_64-pc-windows-gnu` toolchain.
* An FFmpeg 9 **shared** build with import libraries (for example the BtbN `win64-gpl-shared` build):
  the `lib` folder for linking and the `bin` DLLs next to the exe at run time.

## Build

```
set EBS_FFMPEG_LIB=C:\path\to\ffmpeg\lib
cargo build --release
```

`crates/engine/build.rs` reads `EBS_FFMPEG_LIB` to find the FFmpeg import libraries.

The app is `target\release\EBS.exe`. Copy the FFmpeg DLLs (`avcodec`, `avformat`, `avutil`, `swresample`,
`swscale`, ...) next to it before running.

## Notes

* `.cargo/config.toml` points `dlltool` at `tools/dlltool-shim`, a small shim used on the original build PC.
  Change or remove that line if your toolchain has a working `dlltool`.
* `env.sh` is the original build PC's environment script; adjust the paths for your machine.
* FFmpeg struct offsets used by the engine are generated by `tools/ffgen.sh` into `crates/engine/src/ff/gen.rs`.
  Re-run it if you build against a different FFmpeg version.

## Command-line bench

`target\release\ebs-bench.exe` records and tests without the window:

```
ebs-bench hw                       # hardware and encoder info
ebs-bench probe                    # test every encoder in a separate process
ebs-bench record --target pattern  # record a test pattern
ebs-bench presets                  # benchmark SMOOTH / BALANCED / QUALITY
```
